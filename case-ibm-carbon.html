Q1 How did you scale design governance across 14 distributed squads without slowing down agile release trains?
Context / Situation 14 product squads were reinventing UI components, creating massive design debt, hardcoding colors, and failing corporate accessibility audits.
UX Leadership Action I established the Carbon Token Engine and founded the DesignOps Contribution Council. We implemented a 3-tier token hierarchy (Global → Semantic → Component) and automated the sync: when a token updates in Figma, a GitHub Action auto-generates PRs into squad repos via Style-Dictionary.
Business Result Front-end sprint velocity increased by 28%, visual regression defects fell by 70%, and light/dark theme parity was achieved automatically across all 14 squads.
